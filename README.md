# video-tbot

Telegram-бот: присылаете ссылку на публичное видео из YouTube, Instagram или TikTok, выбираете качество и нужны ли заголовок и описание, и получаете видео прямо в чат.

## Почему такие инструменты

| Задача | Выбор | Почему |
| --- | --- | --- |
| Скачивание | [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Один инструмент на все три площадки, бесплатный, быстро чинится при изменениях на сайтах |
| Telegram | [aiogram 3](https://docs.aiogram.dev/) | Асинхронный, не блокируется на долгих загрузках |
| Склейка и MP4 | [ffmpeg](https://ffmpeg.org/) | Без него yt-dlp не соединит отдельные дорожки видео и звука |
| YouTube | [Deno](https://deno.com/) | yt-dlp нужен JS-движок для полной поддержки YouTube |
| Файлы больше 50 МБ | [Локальный Bot API](https://github.com/tdlib/telegram-bot-api) | Поднимает лимит отправки до 2 ГБ, но настраивать его необязательно |

Что не подошло:

- **Официальные API площадок** не отдают файлы чужих видео.
- **Платные API-обёртки** стоят денег и зависят от стороннего сервиса.
- **[cobalt](https://github.com/imputnet/cobalt)** нужно хостить самому, а с yt-dlp отдельный сервис не нужен.

## Запуск в Docker (macOS, Windows, Linux)

Нужен только Docker Desktop: Python, ffmpeg и Deno находятся внутри образа.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.

2. Создайте файл настроек и впишите в него `BOT_TOKEN`:

   ```sh
   cp .env.example .env
   ```

3. Запустите бота:

   ```sh
   docker compose up -d --build
   ```

4. Напишите боту `/start`: он покажет ваш ID. Добавьте его в `ALLOWED_USER_IDS` и примените настройки:

   ```sh
   docker compose up -d
   ```

Логи: `docker compose logs -f bot`. Остановка: `docker compose down`.

Настройки храните только в `.env`: этот файл не попадает в git и в образ. В `.env.example` реальные значения не записывайте.

## Установка на Windows без Docker

1. Установите зависимости и откройте **новый** терминал, чтобы обновился `PATH`:

   ```powershell
   winget install Python.Python.3.13 Gyan.FFmpeg DenoLand.Deno
   ```

2. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.

3. В папке проекта установите библиотеки и создайте файл настроек:

   ```powershell
   py -3.13 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   copy .env.example .env
   ```

4. Впишите в `.env` значение `BOT_TOKEN` и запустите `run.bat`.

5. Напишите боту `/start`: он покажет ваш ID. Добавьте его в `ALLOWED_USER_IDS`, перезапустите бота и пришлите ссылку.

Чтобы бот запускался при входе в Windows, выполните команду, подставив свой путь:

```powershell
schtasks /create /tn video-tbot /sc onlogon /tr "C:\путь\к\video-tbot\run.bat"
```

## Доступ

Бот отвечает только пользователям из `ALLOWED_USER_IDS` и только в личных сообщениях. Иначе любой, кто его найдёт, сможет скачивать видео через ваш компьютер и интернет.

## Лимит 50 МБ

Обычный Bot API принимает от ботов файлы до 50 МБ. Качества, которые заведомо не помещаются, бот в меню не показывает. Размер в меню примерный, поэтому Telegram всё ещё может не принять файл, и тогда бот предложит выбрать другое качество.

Чтобы отправлять файлы до 2 ГБ, поднимите локальный Bot API сервер. В Docker он уже описан в `docker-compose.yml`:

1. Войдите на [my.telegram.org](https://my.telegram.org), откройте **API development tools** и создайте приложение, чтобы получить `api_id` и `api_hash`.

2. Допишите в `.env`:

   ```sh
   BOT_API_URL=http://telegram-bot-api:8081
   TELEGRAM_API_ID=<api_id>
   TELEGRAM_API_HASH=<api_hash>
   ```

3. Остановите бота и один раз отвяжите его от облачного сервера, открыв в браузере `https://api.telegram.org/bot<токен>/logOut`. Вернуть бота на облачный сервер можно будет только через 10 минут.

4. Запустите бота вместе с сервером. Флаг `--profile big-files` нужен и для всех следующих команд `up` и `down`:

   ```sh
   docker compose --profile big-files up -d --build
   ```

Без Docker сервер можно [собрать из исходников](https://tdlib.github.io/telegram-bot-api/build.html) и запустить с флагом `--local`, а в `BOT_API_URL` указать `http://localhost:8081`.

## Если видео не скачивается

- **Перестала работать площадка.** Обычно проблему решает свежая версия yt-dlp. Бот обновляет её сам при запуске и раз в сутки из PyPI. Чтобы отключить это, задайте `YTDLP_AUTO_UPDATE=false`.
- **Instagram или другая площадка требует входа.** Экспортируйте cookies в файл формата Netscape и укажите путь к нему в `COOKIES_FILE`. Используйте отдельный аккаунт: за скачивание его могут заблокировать. Файл с cookies даёт доступ к аккаунту, поэтому никому его не передавайте.
- **Площадка недоступна из вашей сети.** Укажите прокси в `YTDLP_PROXY`.
- **Подробности ошибки** бот пишет в консоль.

## Ограничения

- Прямые эфиры, плейлисты и профили не скачиваются.
- Из карусели Instagram бот берёт только первое видео.
- Посты только с фото не поддерживаются.
